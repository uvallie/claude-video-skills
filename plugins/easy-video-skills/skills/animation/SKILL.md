# Анімація з Claude

Відео — це код. Кожен кадр — функція часу `frame(t)`, що повертає SVG; `@resvg/resvg-js` перетворює його на пікселі, FFmpeg склеює 30 кадрів/с у MP4. Тому будь-який кадр можна перерахувати окремо, правка тексту не ламає решту, а рендер щоразу однаковий. Браузера, Remotion і ШІ-генерації відео немає.

Скрипти й рушій лежать поруч із цим файлом: `${CLAUDE_SKILL_DIR}`.

Спілкуйся з людиною її мовою, простими словами, без жаргону. Людина може вперше бачити термінал — пояснюй, що робиш, одним реченням.

## 0. Знайомство (лише перший раз у проєкті)

Проєкт — це поточна папка. Якщо в ній є `animation.config.json`, знайомство вже було: прочитай його і переходь до кроку 1.

Інакше:

1. **Перевірка.** Запусти `bash "${CLAUDE_SKILL_DIR}/scripts/check.sh" .` і коротко перекажи результат.
2. **Встановлення відсутнього.** Для кожного ❌ запропонуй команду і спитай «ставлю?». Став лише після «так». Mac: `brew install node ffmpeg` (якщо немає Homebrew — інструкція з https://brew.sh). Windows: `winget install OpenJS.NodeJS.LTS Gyan.FFmpeg`. Linux: `sudo apt install nodejs npm ffmpeg`. Не встановлюй нічого, чого немає в списку, без окремої згоди.
3. **Робочі папки й рушій.** Створи `Сценарії/`, `Референси/`, `Готове/`, `fonts/`. Скопіюй `${CLAUDE_SKILL_DIR}/engine` у `./engine` і виконай `npm install` у ній. Якщо є git — додай `.env`, `engine/node_modules/`, `engine/out/` у `.gitignore`.
4. **Коротке інтерв'ю** — по одному питанню, з варіантами, щоб можна було відповісти одним словом:
   - Що робимо найчастіше: пояснення (explainer), покрокова інструкція, анімована обкладинка, промо, мультик з персонажем?
   - Формат: 9:16 (Reels/Shorts/TikTok), 4:5 (стрічка), 1:1, 16:9 (YouTube)?
   - Стиль: є референси? Попроси покласти 3–5 картинок у `Референси/` (скріни ігор, постери, ілюстрації, свій бренд). Немає — запропонуй 3 напрями (наприклад: чистий мінімалізм, піксельна гра, техно-неон) і покажи один кадр у кожному.
   - Персонаж: є (SVG/PNG у `Референси/`) чи без персонажа? Персонаж не обов'язковий — героєм може бути проста фігура.
   - Голос: без голосу (лише субтитри), чи озвучка? Деталі — `references/voices.md`.
   - Картинки з ШІ (фон, ілюстрації, персонаж): потрібні чи ні? Якщо так — `references/image-models.md`.
5. **Стиль словами.** Подивись референси і опиши: кольори з HEX-кодами, форми, контури, шрифти, як рухаються об'єкти. Намалюй один ключовий кадр у 2–3 варіантах (`still()` з рушія) і дай вибрати. Шрифти бренду — у `fonts/` (лише ті, що людина має право використовувати).
6. **Ключі.** Якщо обрано голос або модель для картинок — проведи через `references/voices.md` / `references/image-models.md`. **Ключ ніколи не просимо вставити в чат.** Створи `.env` з порожнім рядком `GEMINI_API_KEY=` (або іншим), відкрий файл людині (`open -e .env` на Mac, `notepad .env` на Windows), хай вставить ключ після «=» і збереже. Потім перевір: `node -e "require('./engine/lib/voice.cjs').check().then(r=>console.log('працює:',r.provider)).catch(e=>console.log(e.message))"`. Значення ключа ніде не друкуй.
7. **Збережи** рішення в `animation.config.json`:

```json
{
  "format": "reel",
  "kind": "explainer",
  "style": { "bg": "#F6F1E7", "ink": "#1B1B1F", "accent": "#C6F432", "warn": "#FFB38A", "final": "#6C4CF5",
             "headFont": "Arial Black", "bodyFont": "Arial", "notes": "словами: форми, контури, як рухається" },
  "character": null,
  "voice": { "provider": "gemini", "voice": "Zephyr", "style": "warm, playful", "tempo": 1.15, "language": "uk" },
  "images": null,
  "rules": []
}
```

`rules` — сюди додавай кожну правку, яку людина хоче бачити завжди («субтитри більші», «без емодзі»). Наступного разу вона не повторюватиме.

Наприкінці знайомства зроби пробний рендер: `cd engine && node scenes/example.cjs --sheet --sound` і покажи розкадровку `engine/out/example-reel-sheet.png`.

## 1. Сценарій → сцени

Людина пише простими словами, що відбувається і скільки секунд (або кладе текст у `Сценарії/`). Розбий на сцени таблицею: № · що відбувається · голос (якщо є) · що на екрані · секунди · рух. Порахуй загальну тривалість. **Нічого ще не рендери** — спершу хай погодить таблицю.

Структура: hook (0–3 с) → основна частина → кінцівка. Деталі й таймінги — `references/motion-rules.md`.

## 2. Сцена кодом

Скопіюй `engine/scenes/example.cjs` у `engine/scenes/<назва>.cjs` і заміни тексти, об'єкти й ключі руху. Що є в рушії:

| Файл | Що дає |
|---|---|
| `lib/motion.cjs` | `E` (easing), `prog`, `kf` (ключі), `jump` (стрибок зі стиском-розтягом), `wave`, `wobble`, `bounce`, `arc` |
| `lib/kit.cjs` | `open/close` (полотно), `text` (поява тексту), `card`, `strike` (закреслення), `check` (галочка); кольори й шрифти з конфігу |
| `lib/render.cjs` | `FORMATS`, `video({name, frame, dur, w, h, audio, sheet})`, `still(file, svg)`, `storyboard` |
| `lib/voice.cjs` | `narrate(lines, {dir})` — репліки з кешем і тривалостями, `mix({parts, music, file})`, `check()` |
| `lib/sound.cjs` | `music(dur)` — тиха фонова музика, `sfx('pop'|'hop'|'land'|'chime'|'whoosh')` — усе синтезоване, без ліцензій |

`text()` не переносить рядки сама: довгий заголовок розбивай на кілька викликів по рядку (у 9:16 — до ~16 символів при 84–88 px) і перевіряй розкадровку.

Прив'язуй візуальні події до початку реплік (тривалості з `narrate`), тоді зміна тексту сама перераховує таймінг. Якщо треба бібліотека, якої немає (наприклад, `gsap` для пружних кривих або `opentype.js` для тексту кривими), спитай і лише тоді став.

## 3. Розкадровка перед повним відео

Спершу рендер з `--sheet` → `engine/out/<назва>-sheet.png` (9 кадрів 3×3). Покажи, запитай, що поправити («блок нижче», «кубик більший»). Це швидше, ніж переробляти готове відео. Перевір сам: чи читається заголовок, чи нічого не налазить, чи важливе в безпечній зоні.

## 4. Відео, голос, звук

- Повний рендер потрібних форматів: `node scenes/<назва>.cjs --format=reel` (і `post`, `square`, `wide`). 16:9 — окрема верстка, не той самий рілз у кутку.
- Голос: `narrate()` → тривалості → `mix()` разом з `sfx` і `music`. Після озвучки транскрибуй або прослухай репліку, якщо можеш, — моделі іноді перекручують слова.
- Готові файли копіюй у `Готове/`. Нічого не публікуй без прямого прохання.

## 5. Правки словами

Людина каже звичайними словами: «зроби неон яскравішим», «стрибок повільніше», «більше зірок». Зміни код сцени, перерендер, покажи розкадровку або стоп-кадр. Якщо правка — про стиль назавжди, допиши в `rules` конфігу.

## Перед тим як віддати

- `ffprobe` — тривалість і розмір збігаються з планом.
- Подивись розкадровку очима (Read на PNG).
- Чесно скажи: звук і плавність руху має оцінити людина — агент не чує й не дивиться відео в реальному часі.
