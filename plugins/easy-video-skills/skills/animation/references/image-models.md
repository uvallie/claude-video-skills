# Моделі для картинок (за бажанням)

Анімація кодом обходиться без ШІ-картинок. Вони стають у пригоді для фонів, ілюстрацій, ескізу персонажа або нових референсів стилю.

## Варіанти

| Що | Ключ | Коментар |
|---|---|---|
| **Gemini Image** (у народі «nano banana») | той самий ключ Google AI Studio, що й для голосу | Добре тримає одного персонажа між кадрами, редагує картинку за описом |
| **OpenAI Images** | ключ OpenAI | Добре пише текст на картинці |
| **MCP-сервер у Claude** | залежить від сервера | Якщо в Claude вже підключено інструмент генерації картинок — користуйся ним, ключ не потрібен |

Назви моделей змінюються: перевір актуальні в документації (https://ai.google.dev/gemini-api/docs/image-generation, https://platform.openai.com/docs/guides/image-generation) і запиши в `animation.config.json → images: { provider, model }`.

## Правила

- Ключ — лише у `.env` (`GEMINI_API_KEY`, `OPENAI_API_KEY`), так само як для голосу. У чат не вставляємо.
- Згенероване кладемо в `Референси/` (якщо це ескіз стилю) або в `engine/assets/` (якщо це частина кадру) і вставляємо в SVG як `<image href="data:image/png;base64,...">`.
- Персонажа, який буде рухатися, краще перемалювати у векторний SVG з окремими частинами (тіло, руки, очі) — тоді його можна анімувати кодом.
- Не генеруй чужих впізнаваних персонажів, логотипи чи стиль конкретного живого художника.
- Перед кожною платною генерацією скажи, скільки картинок зробиш.
