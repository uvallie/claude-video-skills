# Монтаж відео з Claude

Рутину робить Claude, стиль — людини. Усе працює на комп'ютері людини: FFmpeg ріже, кадрує й експортує; Whisper (faster-whisper) розпізнає мову й дає таймінг кожного слова; монтаж — це список шматків, які лишаються (`keeps.json`). Платних сервісів і ключів для базового монтажу не треба.

Скрипти лежать поруч із цим файлом: `${CLAUDE_SKILL_DIR}/scripts`. Проєкт — поточна папка. Проміжні файли — у `.work/`, готові — у `Готове/`.

Спілкуйся з людиною її мовою, просто й без жаргону. Перед довгою операцією кажи, скільки приблизно чекати.

## 0. Знайомство (лише перший раз у проєкті)

Якщо в папці є `montage.config.json` — знайомство вже було: прочитай його й переходь до роботи.

Інакше:

1. **Перевірка:** `bash "${CLAUDE_SKILL_DIR}/scripts/check.sh" .` — коротко перекажи.
2. **Встановлення відсутнього** — для кожного ❌ запропонуй команду й спитай «ставлю?»:
   - Mac: `brew install ffmpeg-full jq` (звичайний `ffmpeg` з Homebrew буває без libass — тоді субтитри не впалюються; скрипти самі знаходять `ffmpeg-full`).
   - Windows: `winget install Gyan.FFmpeg jqlang.jq Python.Python.3.12`. Скрипти — bash: на Windows запускай їх через Git Bash або WSL.
   - Linux: `sudo apt install ffmpeg jq python3-venv`.
   - Python-бібліотеки — в окреме середовище проєкту: `python3 -m venv .venv && .venv/bin/pip install -r "${CLAUDE_SKILL_DIR}/scripts/requirements.txt"`. Перший запуск Whisper докачає модель (~3 ГБ для `large-v3`; на слабкому ноутбуці бери `--model medium` або `small`).
3. **Папки:** `Сирі відео/`, `Референси/`, `Готове/`, `fonts/`. Є git — додай `.work/`, `.venv/`, `.env`, `*.mp4`, `*.mov` у `.gitignore`.
4. **Інтерв'ю** — по одному питанню, з варіантами:
   - Що монтуємо: розмовні рілзи (говорю в камеру), нарізка з довгого ефіру/вебінару, YouTube-відео, подкаст, щось інше?
   - Куди: Reels/TikTok/Shorts (9:16), стрічка (4:5), YouTube (16:9)?
   - Мова відео (для розпізнавання).
   - Стиль: попроси 3–5 відео, які подобаються (файли в `Референси/` або посилання). **Головне правило — надихайся, але не копіюй.** Подивись їх (кадри через `contact_sheet.sh`, звук через транскрипцію) і опиши словами: темп склейок, субтитри (розмір, колір, де стоять, підсвітка слова), музика, переходи, плашки. Запропонуй свій варіант, не копію.
   - Субтитри: вшиті в відео (рілзи) чи окремим файлом (YouTube)? Шрифт бренду — у `fonts/`.
   - Музика: без музики / синтезована кодом (`synth_bed.py`, без ліцензій) / свої треки в `Референси/музика`.
   - Голос або інші моделі — потрібні? Див. «Ключі» нижче. Для звичайного монтажу — ні.
5. **Збережи** в `montage.config.json`:

```json
{
  "kind": "talking-reels",
  "language": "uk",
  "formats": ["reels_9x16"],
  "whisper_model": "large-v3",
  "cuts": { "gap": 0.6, "fillers": ["ееее", "ммм"] },
  "captions": { "burn": true, "style": "Vertical", "font": "Montserrat ExtraBold", "highlight": true },
  "music": { "source": "synth", "gain_db": -18 },
  "style_notes": "що взяли з референсів, словами",
  "rules": []
}
```

Якщо стиль субтитрів відрізняється від стандартного — скопіюй `${CLAUDE_SKILL_DIR}/config/caption_style.ass` у `.montage/caption_style.ass` і зміни там (скрипти беруть файл з проєкту, якщо він є). Так само `.montage/formats.json`.

`rules` — сюди кожну правку «назавжди» («субтитри вище», «без музики на початку»).

## Основний прохід: сире відео → готовий рілз

```bash
S="${CLAUDE_SKILL_DIR}/scripts"; PY=python3; [ -x .venv/bin/python ] && PY=.venv/bin/python
$PY "$S/transcribe.py" "Сирі відео/clip.mp4" --lang uk          # → .work/transcripts/clip.{srt,json,ass,txt}
$PY "$S/keeps.py" .work/transcripts/clip.json --gap 0.6 --drop "ееее,ммм"   # → clip.keeps.json (без пауз)
$PY "$S/cut_edl.py" "Сирі відео/clip.mp4" .work/transcripts/clip.keeps.json .work/clip_cut.mp4
$PY "$S/transcribe.py" .work/clip_cut.mp4 --lang uk             # субтитри вже під змонтоване
bash "$S/reframe.sh" .work/clip_cut.mp4 reels_9x16 crop         # CENTER=0.4 — якщо людина не по центру
bash "$S/burn_captions.sh" .work/formats/clip_cut_reels_9x16.mp4 .work/transcripts/clip_cut.ass
bash "$S/loudnorm.sh" .work/captioned/clip_cut_reels_9x16_captions.mp4 "Готове/clip-reel.mp4"
```

Порядок важливий: **спершу монтаж, потім кадрування, субтитри — останніми** (інакше кадрування обріже текст).

- Перед транскрипцією довгого файлу скажи, скільки чекати: на CPU `large-v3` працює приблизно в реальному часі або повільніше. Для годинного ефіру запропонуй `--model medium`.
- **Перевір субтитри.** Whisper помиляється в назвах і термінах: прочитай `.srt`, виправ у `.json`/`.srt` і перегенеруй `.ass`. Помилки, що повторюються, запиши в `rules`.
- Субтитри для YouTube не вшиваються — віддай `.srt` окремим файлом.

## Нарізка довгого відео на рілзи

1. Транскрипція всього файлу.
2. Прочитай `.txt`/`.srt` і запропонуй 3–7 найсильніших моментів по 20–60 с: тайм-коди, перша фраза (хук), чому це спрацює. Хук має бути в перших 3 секундах — якщо сильна фраза в середині, почни з неї.
3. Після вибору людини: `cut.sh` для кожного → далі основний прохід.
4. Опис і хештеги для кожного — у `Готове/<назва>.txt`.

## Музика й звук

- Синтезована фонова музика без ліцензій: `$PY "$S/synth_bed.py" .work/bed.wav --dur 42 --bpm 84`.
- Зведення під голос: музика на 15–20 дБ тихіша, плавний вхід і вихід:
  `ffmpeg -i video.mp4 -i bed.wav -filter_complex "[1:a]volume=-18dB,afade=t=in:d=1,afade=t=out:st=<dur-2>:d=2[m];[0:a][m]amix=inputs=2:duration=first:normalize=0[a]" -map 0:v -map "[a]" -c:v copy out.mp4`
- Наприкінці — `loudnorm.sh` (−14 LUFS для соцмереж).

## Правки словами

«Зроби хук більшим», «виріж другу хвилину», «субтитри жовті», «повільніше на початку». Зміни `keeps.json`, стиль у `.montage/caption_style.ass` чи параметри — і перерендер лише того, що змінилось (`cut_edl.py` кешує шматки).

## Перед тим як віддати

- `bash "$S/contact_sheet.sh" Готове/<файл>.mp4` → подивись картинку (Read): чи не обрізані голова й субтитри, чи субтитри вище нижніх ~420 px у 9:16 (там інтерфейс Reels).
- `ffprobe` — тривалість і розмір.
- Чесно скажи: звук і ритм має оцінити людина — агент не дивиться відео в реальному часі.
- Нічого не публікуй без прямого прохання.

## Ключі (необов'язково)

Базовий монтаж працює без ключів. Ключ потрібен лише для: озвучки тексту (Gemini TTS, ElevenLabs, OpenAI), перекладу субтитрів моделлю чи генерації обкладинок.

- **Ключ ніколи не вставляємо в чат.** Створи `.env` з порожнім рядком (`GEMINI_API_KEY=`), відкрий його людині (`open -e .env` на Mac, `notepad .env` на Windows), хай вставить ключ після «=» і збереже. `.env` — у `.gitignore`.
- Gemini: безкоштовний ключ на https://aistudio.google.com/apikey. ElevenLabs: https://elevenlabs.io/app/settings/api-keys. OpenAI: https://platform.openai.com/api-keys.
- Назви моделей змінюються — перевір актуальні в документації сервісу під час налаштування.
- Якщо в Claude вже підключено інструмент (MCP) для голосу чи картинок — користуйся ним.
