# Формати, субтитри, корисні команди

## Формати (`config/formats.json`)

| Ключ | Розмір | Куди | Примітки |
|---|---|---|---|
| `reels_9x16` | 1080×1920 | Reels, TikTok, Shorts | субтитри вище ~420 px від низу, верхні ~220 px — під інтерфейсом |
| `feed_4x5` | 1080×1350 | стрічка Instagram, LinkedIn | найбільше місця в стрічці |
| `square_1x1` | 1080×1080 | LinkedIn, X | |
| `youtube_16x9` | 1920×1080 | YouTube | субтитри окремим .srt |

Режими `reframe.sh`: `crop` — обрізати під формат (для людини в кадрі; `CENTER=0.35` зсуває кадр, якщо людина не по центру), `pad` — вписати з чорними смугами, `blur` — вписати на розмитий фон того ж відео (для екранів і слайдів).

## Стиль субтитрів (`config/caption_style.ass`)

Три стилі: `Vertical` (9:16, знизу), `Horizontal` (16:9), `Highlight` (сказані слова жовтіють). Транскрипція пише `.ass` з караоке-тегами `\k`: ще не сказані слова мають колір `SecondaryColour` (сірий), сказані — `PrimaryColour` (білий або жовтий). Довгі фрази переносяться на другий рядок (`WrapStyle: 0`).

Поля, які найчастіше міняють:

- `Fontname` — назва шрифту (файл `.ttf/.otf` у `fonts/` проєкту). Якщо шрифту немає — підставиться системний.
- `Fontsize` — 70–90 для 9:16.
- `PrimaryColour` / `SecondaryColour` — кольори у форматі `&H00BBGGRR` (зворотний порядок: синій, зелений, червоний). Жовтий `#FFE500` → `&H0000E5FF`.
- `Outline`, `Shadow` — товщина обведення й тіні.
- `MarginV` — відступ від низу (420 для Reels).
- `Alignment` — 2 знизу по центру, 5 по центру, 8 згори.

Скопіюй файл у `.montage/caption_style.ass` у проєкті й правь там: скрипти візьмуть його замість стандартного.

`transcribe.py --max-words 3 --max-chars 20` — коротші фрази на екрані (динамічніше), `--max-words 7` — спокійніше.

## Корисні команди FFmpeg

```bash
# прискорити все відео на 10 %
ffmpeg -i in.mp4 -filter_complex "[0:v]setpts=PTS/1.1[v];[0:a]atempo=1.1[a]" -map "[v]" -map "[a]" out.mp4
# стоп-кадр для обкладинки на 3-й секунді
ffmpeg -ss 3 -i in.mp4 -frames:v 1 cover.png
# зменшити файл для надсилання в месенджер (720p)
ffmpeg -i in.mp4 -vf scale=-2:1280 -c:v libx264 -crf 26 -c:a aac -b:a 128k small.mp4
# склеїти кілька кліпів з однаковими параметрами
printf "file '%s'\n" a.mp4 b.mp4 > list.txt && ffmpeg -f concat -safe 0 -i list.txt -c copy joined.mp4
# знайти тишу (для ручного монтажу)
ffmpeg -i in.mp4 -af silencedetect=noise=-35dB:d=0.6 -f null - 2>&1 | grep silence_
```

## Референси

`yt-dlp <посилання> -o "Референси/%(title)s.%(ext)s"` — лише свої відео або з дозволу автора. Референси — для натхнення, не для копіювання: беремо прийоми (темп, розмір субтитрів, як з'являються плашки), не чужий контент.
